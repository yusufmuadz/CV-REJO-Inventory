## BUG KRITIS (harus segera diperbaiki)

1. **`lib/core/network/dio_interceptor.dart:44`** — Kondisi terbalik: `if (statusCode != 401 && isRetry == true)`. Error pertama dengan status **bukan 401** (500/400/timeout, `statusCode == null`) ikut masuk blok refresh token. Jika refresh gagal → `tokenStorage.clear()` (baris 120) → **user ter-logout & token hilang hanya karena error jaringan biasa**. Hanya 401 yang boleh masuk sini.

2. **`lib/features/detail_order/presentation/controllers/detail_order_controller.dart:333-345`** — `final rit = GetStorage().read('city') ?? ''` mengembalikan `String`, lalu dipakai `.value` (`rit.value`, `colorRit.value`, `dateRit.value`, `isRitToday.value`). `String` tidak punya `.value` → **`NoSuchMethodError`** saat driver membatalkan keberangkatan.

3. **`lib/features/scan_product/presentation/controllers/scan_product_controller.dart:220-231` & `266-273`** — Callback permission tidak pernah dipanggil: `onConfirm: () => confirmPermission` hanya mengevaluasi tear-off, dan `confirmPermission({required bool isPermanentlyDenied})` butuh argumen bernama. **Tombol "Izinkan"/"Buka Settings" tidak bereaksi** → alur izin kamera rusak total.

4. **`lib/features/ending_order/presentation/controllers/ending_order_controller.dart:112-117`** — Logika registrasi terbalik: `if (Get.isRegistered<ListOrderController>()) { Get.lazyPut(...) }` lalu `Get.find`. Jika belum terdaftar → `lazyPut` dilewati → `Get.find` **melempar error**; jika sudah terdaftar → `lazyPut` tipe yang sama juga error. Hanya boleh `if (!Get.isRegistered<...>())`.

5. **`lib/features/rit_information/presentation/controllers/rit_controller.dart:105 & 632`** (dan `rit_view.dart:283,288`) — `late final ListOrderController listOrderController;` **tidak pernah di-assign** (hanya ada kode yang di-comment). `_arriveAtOffice()` dan `_openChangeRit()` → **`LateInitializationError`**.

6. **`lib/features/home/presentation/controllers/home_collector_controller.dart:146-308`** — Layar Kolektor memakai **data invoice dummy** hardcode (`TESTING DUMMY CUSTOMER`), sedangkan `getOrder()` (baris 42-124) seluruhnya di-comment → refresh tidak melakukan apa-apa. Ini data palsu yang masih terkirim di build.

7. **`lib/features/home/presentation/widgets/home_collector_driver/list_invoice_widget.dart:165-176`** — Navigasi detail memakai id invoice hardcode `'01SL20200800085'` + snackbar "Invoice Dummy" → tap invoice nyata membuka record yang salah.

8. **`lib/features/list_order/presentation/controllers/get_data_list_controller.dart:195-224`** — `data.first` / `data.first.namaKendaraan!` tanpa cek list kosong, dan komparator sort `a.namaKendaraan!.compareTo(b.namaKendaraan!)` → **`StateError` / `Null check operator`** bila API mengembalikan list kosong atau ada elemen null.

9. **`lib/features/list_order/presentation/controllers/post_data_list_controller.dart:112`** — `loader!.idDeliveryMobil` / `loader!.id` padahal `loader` berasal dari `firstWhereOrNull` → bisa null → crash.

10. **`lib/features/list_order/presentation/views/list_rit_view.dart:46 & 126`** — `int.parse('0xFF${color.replaceAll('#','')}')` dan `DateTime.parse(tanggalRit)`; nilai default field adalah `'-'` (`rit_list_entity.dart:40-41`) → **`FormatException` saat build**.

11. **`lib/features/list_order/presentation/views/list_order_view.dart:160-178`** — `ScrollController` baru dibuat **setiap `build`** dan tidak pernah di-dispose; `removeListener(() {})` adalah no-op yang tidak menghapus apa pun → kebocoran controller + posisi/paginasi kacau.
